Index is the company behind Alloy (alloy.app), an AI-native product-planning and prototyping platform that lets product managers turn any live web app into a pixel-perfect, editable prototype in seconds and ship experiments on real data instead of static mock-ups. Founded by Simon Kubica (ex-Atlassian) and Christian Iacullo (ex-Canva), the company was originally launched as "Index" at index.inc and has since rebranded the product to Alloy. It unifies customer feedback, engineering execution (deep Linear and Jira integration), and design mocks into one workspace of whiteboards, tables, boards, and roadmaps, and exposes an Alloy MCP server so assistants like Claude and Codex can read session design, chat, and code context to accelerate developer handoff. Index is a seed-stage company backed by Bain Capital Ventures. This profile was added to the API Evangelist network as a portfolio-lead stub and enriched from public developer and security surfaces.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Index: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
