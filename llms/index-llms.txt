# Alloy

> Alloy lets Product Managers **turn any live web app into a pixel-perfect, editable prototype in seconds**. Capture real pages and experiment instantly.

Key Benefits:
- Prototype using your existing product
- Matches your design system and automatically uses your real components
- Ship experiments on live data instead of static mock-ups
- One-click “clone & edit” of *any* web page—keeps fonts, spacing, and responsive behavior
- No IDEs or terminals: runs entirely in the browser

Key Features:
- Visual editor to prototype without code
- Issue-tracker support (Linear, Jira) to pull tickets & context directly into the prototype
- Instantly share links for feedback
